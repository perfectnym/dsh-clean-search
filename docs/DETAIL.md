# 清爽搜索 / Clean Search

一个无广告的搜索首页插件，基于 DeepSeek 全家桶（Search / Fetch API）与公开行情、天气接口。

## 功能

- **首页**：一个居中的大搜索栏 + 右上角天气胶囊（默认上海，可在 `cordis.patch.yml` 的 `config.city` 修改），下面是快捷搜索词。首页不展示新闻和行情。
- **搜索**：走 DeepSeek Search API（`POST /v1/tools/search`），不展示广告；结果按「官网优先」排序：
  政府/交易所/监管域名、以及域名命中查询品牌词的结果置顶，并打上「官网」标记。
  Search API 不可用时自动降级到 DSH 已配置的 `ctx.web` 搜索服务。
- **行情（仅搜索结果中出现）**：搜索里出现 `上证指数`、`美元人民币`、`螺纹钢`、`黄金`、`原油`、`恒生指数`、`纳斯达克` 等标的（或直接输入 6 位股票代码）时，
  结果页顶部显示实时报价 + **日 K 线** / **分时图** 切换，支持 A 股、指数、港股、美股、外汇、期货。
- **以图搜图**：搜索栏右侧相机按钮，或右上角入口。上传图片后：
  - 主通道：DeepSeek 联网工具的 `image_search`（模型按图搜索，返回相似图与来源页）；
  - 兜底：多引擎搜索链接（Google Lens / 百度识图 / Yandex / Bing / TinEye / SauceNAO）。

## 数据源与费用

| 能力 | 来源 | 费用 |
| --- | --- | --- |
| 搜索 | DeepSeek Search API | ¥5 / 千次成功搜索 |
| 图搜图 | DeepSeek 联网工具（每张图 1 次） | 按图片搜索次数计费 |
| 天气 | Open-Meteo | 免费 |
| 行情 / K 线 / 分时 | 腾讯证券、新浪财经公开接口 | 免费 |

DeepSeek 凭据取自 DSH 的 credentials 服务（`DEEPSEEK_API_KEY`），不写日志、不回传前端。

## 使用

1. 安装后，左侧栏出现「清爽搜索」图标，点击进入整页。
2. 输入关键词搜索；输入行情标的查看 K 线与分时。
3. 点搜索框右侧相机按钮，选择本地图片做以图搜图。

## 配置（`cordis.patch.yml` 的 `config`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `city` | `上海` | 天气城市 |
| `count` | `10` | 每次搜索返回条数（1–50） |

## 已知限制

- 搜索与图搜图都依赖 DeepSeek API 凭据与计费；没有 key 时搜索降级到 DSH 的 `ctx.web`，图搜图只返回多引擎链接。
- 图搜图的 DeepSeek 通道依赖「模型判断是否发起图片搜索」，不是 100% 触发；未触发时会返回识别文本与兜底链接。
- 行情与天气来自公开免费接口，可能限流或改版；接口失败时对应卡片显示为空，不影响搜索。
- 结果页的「官网」判定基于域名规则与品牌词匹配，不是语义级判断。
